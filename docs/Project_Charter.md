# Project Charter

## Project Title
Marketing Attribution Dashboard

## Project Overview
The Marketing Attribution Dashboard is designed to analyze customer journeys across multiple marketing channels and measure campaign effectiveness using attribution models and business KPIs. The project combines Python, PostgreSQL, and Power BI to build an end-to-end analytics solution.

## Project Objectives

- Analyze customer journeys.
- Implement attribution models.
- Calculate marketing KPIs.
- Build an interactive dashboard.
- Generate business insights for marketing campaigns.

## Project Scope

### In Scope

- Data preprocessing
- Data cleaning
- Attribution models
- KPI calculations
- PostgreSQL database
- Power BI dashboard
- Documentation
- Testing

### Out of Scope

- Real-time streaming data
- Machine learning prediction models
- Production deployment
- Cloud infrastructure
