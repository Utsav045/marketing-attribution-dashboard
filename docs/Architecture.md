# Multi-Touch Marketing Attribution & ROI Dashboard

## System Overview

The system analyzes customer interactions across multiple marketing channels and assigns conversion credit using different attribution models.

## Attribution Models

### First Touch Attribution
100% credit assigned to first interaction.

### Last Touch Attribution
100% credit assigned to last interaction.

### Linear Attribution
Equal credit assigned across all touchpoints.
